# 01 · 板载接线表（CubeMX / .ioc 权威版）

> 来源：解析 `校赛驱动` 里 **11 个例程的 .ioc 文件**，逐个比对得出。
> 结论：**11 个例程的 55 个引脚配置完全一致，零冲突。**
> 说明硬件是**母板固定接线**，你不需要自己飞线；CubeMX 里看到的引脚全是母板已连好的。

---

## 一、摄像头 OV2640（DCMI 并口，11 根）

| 引脚 | 信号 | 说明 |
|---|---|---|
| PC6 | DCMI_D0 | 数据位 0 |
| PC7 | DCMI_D1 | 数据位 1 |
| PE0 | DCMI_D2 | 数据位 2 |
| PE1 | DCMI_D3 | 数据位 3 |
| PE4 | DCMI_D4 | 数据位 4 |
| PD3 | DCMI_D5 | 数据位 5 |
| PE5 | DCMI_D6 | 数据位 6 |
| PE6 | DCMI_D7 | 数据位 7 |
| PA4 | DCMI_HSYNC | 行同步 |
| PB7 | DCMI_VSYNC | 帧同步 |
| PA6 | DCMI_PIXCLK | 像素时钟 |

**8 位并口**，每 2 个时钟拼成 1 个 RGB565 像素。
配置：`GPIO_AF13_DCMI`，`PULLUP`，`VERY_HIGH`。
引脚复用见 `Core/Src/stm32h7xx_hal_msp.c` → `HAL_DCMI_MspInit()`。
DMA：**DMA1_Stream0**，`DMA_REQUEST_DCMI`，Periph→Mem，WORD/WORD。

## 三、1.44 寸屏 ST7735（SPI2 + 4 根控制线）

| 引脚 | 信号 | 说明 |
|---|---|---|
| PB13 | SPI2_SCK | 时钟（CubeMX 标签 `Screen CLK`） |
| PB15 | SPI2_MOSI | 数据（CubeMX 标签 `Screen MOSI`），**只发不收** |
| PB12 | GPIO_Output | CS 片选，低有效 |
| PB1 | GPIO_Output | DC，0=命令 1=数据 |
| PB14 | GPIO_Output | RST 硬复位，低有效 |
| PB0 | GPIO_Output | BLK 背光，高亮 |

SPI2 时钟 = PLL1Q 48MHz ÷ 2 = **24 MHz**。
引脚与宏定义见 `Core/Inc/lcd_144.h`。

## 十一、最容易搞混的三件事

| 疑问 | 答案 |
|---|---|
| 摄像头是不是要自己接 11 根线？ | **不用**，母板已连好，排线插上就行 |
| 摄像头和 IMU 会不会抢同一条 I2C？ | **不会**，摄像头 I2C2、IMU I2C1 |
| 屏幕和 SD 卡会不会抢 SPI？ | **不会**，屏幕 SPI2、SD 卡走 SDMMC1（不是 SPI 模式） |

## 十二、改动接线时要注意

1. **不要在 CubeMX 里随便改引脚**，母板是画好的，改了就对不上硬件。
2. 要加新外设，先看上面表里哪些引脚是空闲的（`PA7 / PC4 / PC13` 这三个是 GPIO，可能是预留）。
3. 改完 `.ioc` 一定要**重新生成代码**，否则 `main.c` 里的 `MX_xxx_Init()` 不会更新。
